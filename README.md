# 👾 Ghousia | Software Engineer & Full-Stack Architect Portfolio

A high-performance, responsive personal portfolio website with a retro **Pixel Art / 16-bit RPG aesthetic** built with semantic HTML5, modern CSS custom properties, and vanilla JavaScript.

---

## ✨ Features

- **🎮 16-Bit Pixel Art Theme**: Custom pixel typography (`Press Start 2P`, `Silkscreen`), 8-bit stepped borders, scanline CRT effects, and retro HUD elements.
- **🌓 Adaptive Theme Engine**: Automatic detection of OS/browser light/dark mode via `@media (prefers-color-scheme)` + persistent manual toggle.
- **📱 Left-Side Vertical Sidebar**: Fixed on desktop, transforms into an accessible slide-out mobile drawer on small screens.
- **📂 Interactive Project Cards & Modal**: Clickable thumbnails opening detailed technical specs, challenges solved, and repo/live links.
- **🎬 Responsive Video Highlight**: Scalable 16:9 arcade TV bezel for architectural video showcases and demos.
- **💬 Peer Testimonials**: Structured endorsements from engineering leaders with star ratings.
- **🤖 AI Companion Chatbot**: Simulated AI assistant that responds to visitor inquiries about skills, experience, and availability.
- **✉️ Contact Form**: High-contrast pixel transmission interface with confirmation alerts and API hooks.
- **♿ Fully Accessible (a11y)**: Complete ARIA labels, semantic landmark elements, and keyboard navigability.

---

## 🚀 Quick Start & Local Preview

Simply open `index.html` in any web browser:

```bash
# On Windows PowerShell
Start-Process index.html
```

Or run any local web server:
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
